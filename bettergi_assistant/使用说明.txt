BetterGI 远程辅助程序 · 绿色免安装版
==================================================

双击「启动.bat」即可运行，目标电脑不需要安装 Python，
也不需要联网装依赖（解释器和 httpx / psutil / pyyaml 都在 python 目录里）。


一、目录结构
--------------------------------------------------
启动.bat        程序入口（双击运行，带交互菜单）
launcher.py     功能菜单：启动 / 停止 / 自启 / 配置 / 测试 / 日志
server.py       辅助程序本体（连接 AstrBot，执行 BetterGI 指令）
config.yaml     配置文件，第一次使用前请改这里
python\         内置的 Python 3.13 运行环境，请勿删除或改名
assistant.log   运行日志（启动后自动生成）


二、第一次使用
--------------------------------------------------
1. 打开 config.yaml，填好三项：
     astrbot_url  AstrBot 的访问地址，例如 http://192.168.1.100:6185
     bettergi_dir BetterGI 的安装目录，例如 D:\BetterGI
     api_key      AstrBot 管理面板 → 设置 → OpenAPI 里创建的密钥
                  （权限只勾选 plugin，有效期选永久，复制 abk_ 开头的整串）
   也可以在菜单里选 8「修改配置」交互填写。

2. 双击「启动.bat」，菜单选 7「测试连接 AstrBot」，
   显示「连接成功」说明地址和密钥没问题。

3. 菜单选 2「后台启动（无窗口）」，辅助程序开始常驻。

4. 想让电脑开机后自动跑：菜单选 4「注册开机自启」。
   取消用菜单 5。


三、菜单功能
--------------------------------------------------
1  前台启动，日志直接显示在窗口里，Ctrl+C 停止（排查问题用这个）
2  后台启动，无窗口常驻
3  停止后台运行的辅助程序
4  注册开机自启（优先计划任务，失败自动回退注册表 Run 项）
5  取消开机自启
6  查看自启状态
7  测试连接 AstrBot
8  修改配置（直接回车＝保留原值）
9  查看运行日志
10 检查运行环境
0  退出


四、命令行用法（可选）
--------------------------------------------------
在目录里打开命令提示符，执行：

  python\python.exe launcher.py            进入菜单
  python\python.exe launcher.py --start    前台启动
  python\python.exe launcher.py --daemon   后台启动
  python\python.exe launcher.py --stop     停止后台进程
  python\python.exe launcher.py --status   查看配置 / 进程 / 自启状态
  python\python.exe launcher.py --test     测试连接
  python\python.exe launcher.py --log      查看最近日志
  python\python.exe launcher.py --install  注册开机自启
  python\python.exe launcher.py --uninstall 取消开机自启


五、常见问题
--------------------------------------------------
Q: 提示「找不到内置 Python 运行环境」
A: 压缩包没解压完整。请把整个 zip 解压出来再运行，不要只复制
   启动.bat 或 python 目录的一部分。

Q: 提示「配置文件不存在 / 配置需要补全」
A: 首次运行会引导你补全，也可以菜单选 8 手动填写。

Q: 连接失败 / 认证失败 (401、403)
A: 依次检查：AstrBot 是否启动、地址端口是否正确、
   防火墙是否放行、api_key 是否完整且勾选了 plugin 权限。

Q: 接口不存在 (404)
A: 插件没有加载或版本太旧，确认 AstrBot 里的 BetterGI 插件已启用
   且为 2.1.x（远程模式使用 SSE 接口）。

Q: 双击后窗口一闪就没了
A: 别直接关窗口。先选 1 前台启动，错误信息会留在窗口里。

Q: 换电脑后怎么用
A: 整个目录打包拷过去即可（换盘符、换路径都不影响）。
   开机自启记录是当前用户级的，换电脑需要在新机器上重新注册一次。

Q: 杀毒软件报毒
A: 本程序没有加壳、没有联网下载行为，只是 Python 解释器 + py 脚本。
   如果被拦截，把整个目录加入白名单。
